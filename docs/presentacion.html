Generalidades del proyecto

Resumen

Sistema de préstamo de herramientas para un laboratorio basado en dos autómatas finitos: uno administra el inventario y otro controla la operación física. Una cámara con un modelo YOLO11n-cls verifica visualmente la herramienta antes de autorizar cada transición, y SQLite conserva préstamos e historial. El prototipo se valida con un martillo, puerta y sensores simulados, portal web local y monitor sincronizado en tablet.

Palabras clave

Autómatas finitos · Visión artificial · Préstamo de herramientas · YOLO · Verificación visual

Abstract

A tool-lending system for a laboratory, built on two finite automata: one manages the inventory and the other controls the physical operation. A camera with a YOLO11n-cls classification model visually verifies the tool before authorizing each transition, while SQLite stores loans and history.

Keywords

Finite automata · Computer vision · Tool lending · YOLO · Visual verification

Research Problem

In a laboratory there is no reliable record of who takes a tool, simultaneous loans of the same unit are possible, and returns are not verified.

Manual control depends on memory and trust, which leads to losses and unavailable tools.

Research question: how to guarantee that each loan and return is authorized, unique and visually verified, using a deterministic control model (finite automata) combined with real-time computer vision, before investing in the physical cabinet hardware?

Justificación

Técnica

Un AFD elimina ambigüedad en las transiciones; cada evento inválido se rechaza y se registra, y la verificación visual exige evidencia nueva tras cada operación.

Práctica

Reduce pérdidas y préstamos simultáneos sin vigilancia permanente; una restricción única en SQLite impide dos préstamos activos del mismo martillo.

Académica

Aplica de forma medible la teoría de autómatas y lenguajes regulares (AFD reconocedor de trazas válidas) junto con visión artificial en un caso real.

Económica

Funciona con hardware de bajo costo (computador + celular como cámara) y sin internet; la maqueta física solo se construye tras validar el software.

Marco Teórico o Conceptual

AFD del inventario: M = (Q, Σ, δ, q₀, F) con 5 estados y 7 símbolos; las trazas aceptadas terminan en Disponible (lenguaje regular de ciclos válidos).

Visión artificial: YOLO11n-cls con 5 clases (martillo, destornillador, alicate, vacío, otros); estabilidad con umbral 0,85, ≥ 5 observaciones y ≥ 2 s.

Objetivos

Objetivo general

Diseñar e implementar un prototipo de sistema de préstamo de herramientas basado en autómatas finitos y visión artificial, que autorice, registre y verifique cada retiro y devolución en un laboratorio.

Objetivos específicos
  • Modelar el inventario y la operación física como AFD con trazas de validación.
  • Implementar el controlador, la persistencia en SQLite y el portal web con monitor sincronizado.
  • Construir un dataset propio de cinco clases y ajustar YOLO11n-cls con evaluación documentada.
  • Validar el sistema con diez ciclos completos de préstamo/devolución con cámara real.

Expected Results

  • A working prototype that authorizes, records and verifies every loan and return, rejecting invalid events deterministically.

  • A custom image dataset (five classes, ~100 images per class) and a fine-tuned YOLO11n-cls model with documented confusion matrix, accuracy and false positives.

  • Measured results from ten complete loan/return cycles with the real camera, including latency and visual evidence.

  • An academic validation of finite automata and regular languages applied to access control.

  • A validated software base ready for the next milestone: the physical cabinet with real door and presence sensors.
