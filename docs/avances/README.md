# Paquete de avances 3 4 y 5

Este índice reúne el desarrollo académico y los soportes para revisar, explicar y completar el proyecto de préstamo de herramientas. Los archivos Markdown son la fuente de contenido. El montaje de entrega debe respetar las plantillas oficiales de Word y PowerPoint, especialmente las secciones VII y VIII; la plantilla Word no está disponible en este repositorio. Hay presentaciones previas en `docs/`, cuya correspondencia con la plantilla vigente debe confirmarse.

## Documentos principales

1. [Avance 3 Metodología](../AVANCE3_METODOLOGIA.md): enfoque, objetivos, fases, herramientas, validación y organización.
2. [Avance 4 Análisis](../AVANCE4_ANALISIS.md): contexto, actores, requisitos, procesos y casos de uso.
3. [Avance 5 Diseño](../AVANCE5_DISENO.md): arquitectura, funciones, datos, interfaces y diagramas.

## Ruta para cerrar la entrega

Primero revisar el alcance y los requisitos entre todos los integrantes. Después diligenciar nombres, institución, observaciones del contexto y fechas reales en el plan. Integrar el contenido y las figuras en las plantillas oficiales. Ensayar el guion y la demostración; registrar cualquier prueba real que se complete. Revisar en equipo la coherencia entre Word y PowerPoint antes de entregar.

No confundir el cumplimiento documental con validación experimental: la evidencia automatizada cubre escenarios controlados; el dataset, las métricas del modelo y los ciclos con cámara se completan con los dispositivos y herramientas reales.
